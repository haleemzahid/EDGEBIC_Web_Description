**The shift production report in EDGEBIC by User Solutions lives in the Reports hub: it takes a date range and returns planned versus actual hours, pieces, and an operator count for each work center per day, each row carrying an on-rate status badge.** It is the daily production picture with the people added: how much a station ran, how much it made, and how many operators were on it.

It shares its source data with [daily production totals](/blog/how-to-see-daily-production-totals-in-edgebic) and adds the operator count on top, so read that first for the base view and this for the staffing layer. Both depend on hours and punches being logged, which is covered in [logging actual hours and pieces](/blog/how-to-log-actual-hours-and-pieces-in-edgebic). Every task in this library is mapped on the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- Actual hours are being logged. The report compares planned against actual, so an unlogged shop shows planned hours only.
- Operators are punching in through the kiosk if you want the operator count to populate. The count comes from punches, not a roster.
- You know the window you want. The report takes a From and To date range.

## Step 1: Open the Report and Set the Window

Open Reports from the main navigation and click the **Shift Production** card. A date range dialog appears. Set the From and To dates, then click OK. The report groups production by work center and day and builds one row per station per day.

## Step 2: Read a Row

Each row is one station on one day:

- **Planned hours** and **actual hours**, the plan against the logged reality.
- **Actual pieces**, the output logged for that station and day.
- **Operator count**, the number of distinct operators who punched in on that station.
- **Status badge**, a quick read of the hours gap: on rate when actual and planned are within a quarter hour, a negative figure when the station logged fewer hours than planned, or an overtime figure when it ran longer.

## Step 3: Use the Status Badge for End-of-Day Triage

Run the report for today only and scan the status badge column. On rate is the healthy majority. The rows that read a shortfall or overtime are your handful of stations to ask about while operators are still on shift and the answer is fresh. A shortfall usually means a late start, a breakdown, or unlogged time; overtime means genuine extra hours or a duplicate punch.

## Step 4: Correlate Staffing With Output

Sort by operator count to compare output on low-staffing days against high-staffing days on the same station. Where the operator count reads zero next to real hours, you have found a station whose time is being captured without kiosk punches, which is a usage gap to close rather than an idle machine.

## Understanding the Combined Shift Label

Every row currently labels the shift as Combined, because the report groups by work center and day rather than by named shift. The totals are accurate; they are simply not yet split across your first, second, and third shifts in separate columns. For a per-shift read today, narrow the date window and cross-reference your shift calendar. The Combined row still gives you the day's planned-versus-actual story per station.

## How to Check It Worked

The report is read-only, so nothing is saved. Confirm it worked by checking a station where you know both the hours and who ran it: the actual hours and operator count should match your expectation. If the operator count is zero on a station you know was staffed, the operators were not punching in through the kiosk.

## Common Mistakes

- **Reading a zero operator count as an empty station.** The count comes from punches. Hours without operators is a kiosk gap, not idle time.
- **Expecting per-shift columns.** Output rolls into a Combined row per station per day. Narrow the window for a per-shift read.
- **Ignoring the status badge.** It is the fastest triage signal on the report. The not-on-rate rows are where the day's questions are.
- **Running a wide window for end-of-day checks.** For same-day correction, set the window to today only so the rows reflect the shift you can still ask about.
