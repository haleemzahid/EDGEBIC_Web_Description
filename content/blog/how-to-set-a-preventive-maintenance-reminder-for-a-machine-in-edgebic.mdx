**To set a preventive maintenance reminder for a machine in EDGEBIC by User Solutions, set a maintenance interval in days on the work center and record the date of its last service.** The kiosk compares today against the last service date plus the interval and shows a PM-due banner when the machine is overdue, so the operator sees the warning at the point of work.

This is a reminder, not a schedule change. It tells you when service is due; it does not reserve the hours. This page covers the reminder, and points you to the downtime tools that actually block the time. For the wider machine model, start with [work centers explained](/blog/edgebic-work-centers-explained).

## Before You Start

- **The work center already exists** ([how to add a work center](/blog/how-to-add-a-work-center-in-edgebic)).
- **You know the service interval** in days, and the date the machine was last serviced.
- **Operators work this machine through the kiosk,** since the banner surfaces there.

## Step 1: Open the Work Center for Editing

Open the **Work Centers** area and select the machine. Click **Edit** to open its configuration.

## Step 2: Set the Maintenance Interval

Set the **Preventive Maintenance Interval Days** to the cycle length. A monthly cycle is 30 days; a quarterly cycle is roughly 90. Leaving this blank turns PM tracking off for the machine, so the reminder is opt-in.

## Step 3: Record the Last Service Date

Set the **Last Preventive Maintenance Date** to the day the machine was most recently serviced. The kiosk counts the interval forward from this date to decide when the machine is due.

## Step 4: Save

Click **Update**. PM tracking is now active for the machine.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Kiosk for this machine | Shows a PM-due banner once the interval has passed since the last service date |
| The schedule | Unchanged; the reminder reserves no hours and moves no jobs |
| Setting the interval blank | Turns the banner off for the machine |

The reminder and the plan are deliberately separate. EDGEBIC will not automatically pull the machine out of the schedule when PM is due. To take the hours out while service happens, add a downtime event, covered in [how to schedule a downtime event for a machine](/blog/how-to-schedule-a-downtime-event-for-a-machine-in-edgebic), or a per-day override for a full day, covered in [how to block a machine for a maintenance day](/blog/how-to-block-a-machine-for-a-maintenance-day-in-edgebic).

## Choosing the Interval

The interval is in days, counted from the last service date. Match it to how the machine is actually maintained:

| Cycle | Interval in days |
|---|---|
| Weekly | 7 |
| Monthly | 30 |
| Quarterly | 90 |
| Semi-annual | 180 |
| Annual | 365 |

If a machine is serviced on running hours rather than calendar days, pick the day interval that roughly matches its typical duty, and reset the last-service date each time so the banner tracks real service rather than drifting.

## Pairing the Reminder With a Block

The reminder and a downtime block work as a pair. A worked case: a furnace on a 30-day PM cycle is set with an interval of 30 and a last-service date of the first of the month. Around the thirtieth, the kiosk shows the PM-due banner to the operator. The planner, seeing the cycle coming, adds a downtime event or a per-day override for the four-hour service window so the plan stops promising work through it. When the service is done, the technician updates the last maintenance date to the service day, the banner clears, and the next 30-day count begins. The reminder answers when service is due; the block answers where the hours go. Used together, they keep both the operator and the schedule honest about maintenance.

## How to Check It Worked

1. Set the interval and a last-service date far enough in the past that the machine is overdue, and confirm the kiosk shows the PM-due banner.
2. After a service, update the last maintenance date to the service day and confirm the banner clears.
3. Confirm the plan is unchanged: no bars moved just from setting the reminder.

## Common Mistakes

**Expecting the reminder to reserve time.** It only warns. Pair it with a downtime event or a per-day override to actually protect the service window in the plan.

**Leaving the interval blank.** PM tracking is opt-in. No interval means no banner, however overdue the machine is.

**Not resetting the last-service date.** After maintenance, update the date. An out-of-date value makes the banner fire early or late relative to real service history.

**Looking for the banner on the planning grid.** It surfaces at the kiosk where the operator works the machine, not on the planner's work center grid.
