**To rename on-screen labels in EDGEBIC, open Settings and then the Localization tab, type your preferred wording into the Alternative column for any label, turn on the Use alternate strings toggle, and click Save.** EDGEBIC by User Solutions lets an administrator rename tab captions, button labels, and column headers to match plant vocabulary, for example changing Workcenter to Machine Group, and the change is presentation only: nothing about the data or the schedule changes.

This post covers the Localization tab. For the wider map of what is presentation versus what is policy, see [EDGEBIC configuration options explained](/blog/edgebic-configuration-options-explained); the full task library is at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## How the label set is built

Each row on the Localization tab pairs a Key, the shipped Default text, and an Alternative you fill in. Type nothing and the Key keeps its default; type a term and, once the Use alternate strings toggle is on, that term appears wherever the Key is used. Because the substitution is by Key, one alternative renames a caption everywhere it shows, so you change the word once rather than screen by screen. Treat the set as a deployment-level presentation choice made by an administrator, not a personal preference: agree the vocabulary as a team, then Export all so a second station or a reinstall shows exactly the same wording. Nothing about the data, the reports, or the schedule changes; only the words on the surface do.

## Before You Start

- You can reach the **Settings** tab; it is permission-controlled.
- You have agreed the vocabulary as a team, since a label set applies where it is turned on, not per person.
- You understand this changes text only, never data or the plan.

## The Steps

1. **Open the Localization tab.** From the main navigation open **Settings**, then the **Localization** sub-tab.
2. **Find the label.** Each row shows the **Key**, the **Default** text as it ships, and an empty **Alternative** column. Scan or search for the caption you want to change.
3. **Type your wording.** In the **Alternative** cell, type the term you want, for example `Machine Group` in the row whose Default reads the work-center caption. Leave the Alternative blank on any row to keep its default.
4. **Turn on alternatives.** Switch on the **Use alternate strings** toggle. This flips the whole application from defaults to your alternatives. Edits are live, so you see the captions change.
5. **Save.** Click **Save** to persist the label set.
6. **Reuse it elsewhere (optional).** Use **Export all** to save your label set to a file, and **Import** to load it on another machine, so a reinstall or a second station uses the same wording.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Tab captions, buttons, column headers | Show your alternative text wherever a Key is renamed. |
| The Use alternate strings toggle | Switches the whole application between defaults and your alternatives. |
| Blank Alternative rows | Fall back to the Default text automatically. |
| The data and the schedule | Nothing. Only the on-screen wording changes. |
| Another machine | Picks up the same wording when you Export all and Import the set. |

## How to Check It Worked

After saving with the toggle on, look at a screen you renamed, for example the navigation tab whose caption you changed. The new wording should appear in place of the default. Turn the **Use alternate strings** toggle off and Save to confirm the defaults return; turn it back on to restore your wording. If the label flips cleanly both ways, your alternatives are stored correctly.

## Common Mistakes

**Expecting a rename to change data.** A renamed caption is text only. The record, the report field, and the scheduler's math are unchanged. If you were hoping to rename a data field itself, this is not the tool.

**Leaving the toggle off.** Typed alternatives do nothing until Use alternate strings is on. If your new wording is not showing, check the toggle before checking the rows.

**Renaming labels one machine at a time.** Retyping alternatives on every station invites drift. Export the set once and Import it, so every station reads the same vocabulary.

**Hunting through defaults to undo an experiment.** You do not have to. Turn the toggle off to show defaults while keeping your alternatives, or use Reset all alternatives to clear them entirely.
