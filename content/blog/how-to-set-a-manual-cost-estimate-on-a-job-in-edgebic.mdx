**To set a manual cost estimate on a job in EDGEBIC by User Solutions, open the manufacturing order and type a value into the Manual Est. Cost field, either in the edit dialog or inline in the Orders grid, then save.** From then on, variance reports compare logged actual cost against your entered figure rather than the cost EDGEBIC rolls up automatically from the routing and work center rates. Clearing the field reverts the comparison to the automatic rollup. This is a reporting override, not a schedule or price change.

This is one specific task. For the price side of a job, see [how to set a markup on a quote](/blog/how-to-set-a-markup-on-a-quote-in-edgebic). The full task set lives on the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- The manufacturing order exists and is saved. A manual estimate attaches to a specific order.
- The figure you want to use, as a decimal amount. This is usually a quoted or negotiated total you are accountable for.
- An understanding that this is a variance reference only. It does not set the sales price or move any operation.

## Step by Step

1. Open the **Orders** tab in Drive Schedule.
2. Select the job's row. Click **Edit** (the pencil), or click directly in the **Manual Est. Cost** column to edit inline.
3. Type the manual estimated cost as a decimal, for example 8000.
4. Click **Save** (or the highlighted **Save Changes** button after an inline edit).

## What Changes When You Save

Saving stores your figure as the order's manual estimated cost. Variance displays in the reports now use this value as the reference baseline instead of the automatically rolled-up estimated cost. The rollup still exists and still recalculates when the routing or rates change, but it is no longer the number variance measures against while a manual estimate is present. Nothing about the schedule moves, and the sales price is untouched, because those are set from capacity and from markup respectively.

The change is per job, so every other order keeps its automatic rollup as its reference. This makes a manual estimate a safe, targeted edit for the one job where a quoted number differs from the routing math.

## How to Check It Worked

Open a report that shows cost variance for the job, such as a job cost or earned value view. The reference or planned cost column should now read your entered figure rather than the rolled-up estimate. Log or import some actual cost, then confirm variance is computed against the manual number. If the report still shows the rollup, confirm the manual estimate saved on the correct order and that the field is not blank.

## Common Mistakes

- **Expecting the price to change.** The manual estimate is a cost reference for variance, not the customer price. Set price through [how to set a markup on a quote](/blog/how-to-set-a-markup-on-a-quote-in-edgebic) or a typed unit price.
- **Confusing it with the product cost.** The manual estimate is per job. The standard cost of the item is a product-level field, set elsewhere.
- **Leaving a stale figure in place.** If the manual number no longer reflects reality, clear it so variance returns to the live rollup.
- **Editing the wrong order.** Inline edits apply to the selected row. Confirm the job number before saving.
