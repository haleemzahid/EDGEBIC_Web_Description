**To clear a job's schedule in EDGEBIC by User Solutions, tick the job on the Orders grid and click Clear Schedule.** That deletes the production schedule, operation, and resource rows for the selected jobs and marks each as not scheduled. The manufacturing orders and all master data stay, and the planner-entered start date is kept on purpose because it is an input, not a scheduling output.

Clearing a plan is not the same as deleting a job. It removes only what the scheduler produced, which makes it the right tool for two jobs: forcing a fresh routing read, and taking a cancelled job's bars off the board without losing the order.

## Before You Start

- **You know which jobs you want cleared.** Selection scopes the action.
- **You know the difference between scoped and full.** No selection means a full wipe of all schedules.
- **You know the start date survives.** Clearing does not reset planner inputs.

## Step 1: Open the Orders Grid

Open the **Drive Schedule** tab and go to the **Orders** grid.

## Step 2: Select the Jobs to Clear

Tick the checkbox in the leftmost column for each job whose schedule you want removed.

This selection is what keeps the action scoped. If you leave every row unticked and click Clear Schedule, the action becomes a full wipe of all schedules in the plan, which is a different and much larger operation.

## Step 3: Click Clear Schedule and Confirm

Click **Clear Schedule**. A scoped confirmation appears, naming the number of selected jobs. Read it to make sure the count matches what you intended, then click **Yes**.

The selected jobs' production schedule, operation, and resource rows are deleted, and each job's status returns to not scheduled.

## Step 4: Rerun If You Cleared to Refresh a Routing

If the reason you cleared was to force a fresh routing read after a master-routing edit, run **Schedule** now. The next run reads the current routing for the cleared jobs and rebuilds their plan with the updated steps.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Production schedule, operation, resource rows | Deleted for the selected jobs |
| Manufacturing order | Kept; marked not scheduled |
| Start time and target start date | **Preserved.** They are planner inputs |
| Other jobs | Untouched when the action is scoped |
| A selected Completed job | Reopened to Scheduled; posted stock reversed auditably |

## How to Check It Worked

1. Confirm the cleared jobs show blank start and end dates on the Orders grid and read as not scheduled.
2. Confirm their start time is still set, since that is a planner input the clear does not touch.
3. On the Job View, confirm the cleared jobs have no bars while other jobs are unchanged.
4. If you cleared to refresh a routing, rerun and confirm the new step durations appear.

## Common Mistakes

**Deselecting everything, then clicking Clear Schedule.** With no selection, the action is a full wipe of the entire plan, not a scoped clear. Confirm the dialog names the number you expect.

**Including a completed job by accident.** A selected Completed job is reopened and its stock is reversed. That is correct, but only include it if you meant to.

**Expecting the start date to reset.** It does not. Start time and target start date are planner inputs and survive the clear. Change them in the order edit if you want them different.
