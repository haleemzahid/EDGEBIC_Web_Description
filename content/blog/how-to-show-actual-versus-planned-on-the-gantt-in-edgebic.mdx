**To show actual versus planned on the EDGEBIC Gantt, open the Schedule View Configuration tab, go to the Manufacturing tab, and use the Actual Date Tracking card: turn on Show Actual Dates Overlay, Show Variance Indicator, and Show In-Progress, set the Variance Threshold in minutes, then Save and Apply Now Configuration.** The overlay in EDGEBIC by User Solutions draws real dates against the planned bar so you can compare reality to plan without opening anything, and it is display only, so it changes nothing the engine computed.

This post covers the one card. To read the planned-versus-actual picture it produces, see [reading the EDGEBIC Gantt: planned versus actual](/blog/reading-the-edgebic-gantt-planned-vs-actual); the full task library is at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- You can reach the **Schedule** area and its **Schedule View** sub-tab.
- Some operations have actual dates logged, so there is a real position to overlay against the plan.
- You understand that these are display settings, tuned per user and per machine.

## The Steps

1. **Open the Schedule area** and select the **Schedule View** sub-tab.
2. **Click the Configuration tab** and switch to the **Manufacturing** tab.
3. **Open the Actual Date Tracking card** and set:
   - **Show Actual Dates Overlay**: draws actual start and end markers against the planned bar.
   - **Show Variance Indicator**: flags operations whose actual differs from plan beyond the threshold.
   - **Show In-Progress**: highlights started-but-unfinished operations.
4. **Set the Variance Threshold (min)** to the smallest drift worth flagging (the default is 30).
5. **Adjust the overlay colors** if you want (actual start, actual end, early and late variance, in-progress each have their own).
6. **Click Save and Apply Now Configuration.**

## What Changes When You Save

| Setting | Effect on the bars |
|---|---|
| Show Actual Dates Overlay | Actual start and end markers appear against the planned bar. |
| Show Variance Indicator | Operations past the threshold light up in the early or late variance color. |
| Show In-Progress | Started-but-unfinished operations are highlighted (orange by default). |
| Variance Threshold (min) | Sets how much drift is needed before the variance flag appears. |
| The plan | Nothing. The overlay is presentation only. |

The overlay colors are yours to set. By default the actual start marker is blue, the actual end is green, an early variance is green, a late variance is red, and the in-progress highlight is orange. Change any of them on the same card if your plant reads a different color language, then apply. Because these are per-user display settings, a supervisor station and a planner station can each carry the treatment that suits the person using it without either one affecting the plan.

## How to Check It Worked

Pick an operation you know finished late and confirm the overlay draws its actual end past the planned end, with the late variance color if the drift exceeds your threshold. Pick an operation that started this morning but has not finished, and confirm it shows the in-progress highlight. If nothing appears, check that the operation actually has actual dates logged; the overlay has nothing to draw against a bar that is still purely planned.

## Common Mistakes

**Setting the threshold to zero.** A threshold of zero flags almost every bar, because tiny routine differences count as variance. Set it to a value you would act on, typically 30 to 60 minutes.

**Expecting the overlay on unlogged operations.** The overlay draws actual dates. An operation with no actuals shows only its planned bar; that is correct, not a fault.

**Recoloring operation states here.** This card colors the overlay markers and in-progress highlight, not the operation-state bars (Applied, Resource Replaced, and so on). Those live in the operation-states list on the General tab.

**Assuming everyone sees your overlay.** These are per-user display settings. A colleague on another station keeps their own overlay configuration until they Import yours.
