**To set how far the Gantt timeline scrolls in EDGEBIC, open the Schedule View, go to the Configuration tab, and on the General tab use the Timeline Limits group to turn on Use Timeline Limits, set the Start Limit, and add Buffer Weeks, then click Save and Apply Now Configuration.** The timeline is then bounded to the scheduled range plus your buffers. These are display settings and do not change the schedule.

Left unbounded, a Gantt can scroll far past the last job into empty time, which makes it hard to keep the real work in view. EDGEBIC by User Solutions bounds the visible range with Timeline Limits: a start edge, an end edge, and buffer weeks on each side. This is distinct from zoom, which changes how much fits on screen; limits change how far you can scroll at all.

## Before You Start

- **Your Gantt scrolls into empty space** or clips a job at an edge.
- **You can reach the Configuration tab.** It sits in the Schedule View beside the Scheduler sub-tab.
- **You understand this is display only.** Limits never move a job or change capacity.
- **You know your scheduled range.** The default start bound follows the earliest scheduled start.

## Step 1: Open the Configuration Tab

Open the **Schedule** tab, then the **Schedule View** sub-tab, then select **Configuration**. Stay on the **General** tab.

## Step 2: Find the Timeline Limits Group

Locate the **Timeline Limits** group.

| Setting | Default | What it changes |
|---|---|---|
| **Use Timeline Limits** | On | Bounds how far the timeline scrolls |
| **Start Limit** | EarliestStartDate | The timeline begins at the earliest scheduled start, or NoLimit for no left bound |
| **Start Limit Buffer Weeks** | 1 | Extra weeks shown before the computed start |

An equivalent End Limit pair controls the right edge.

## Step 3: Set the Bounds

Turn on **Use Timeline Limits**. Set **Start Limit** to **EarliestStartDate** so the view begins at the first scheduled job, or **NoLimit** to scroll freely before it. Set **Start Limit Buffer Weeks** to give breathing room before that start, then set the End Limit pair the same way for the right edge.

## Step 4: Apply the Change

Click **Save and Apply Now Configuration** at the bottom. The timeline redraws with the new bounds.

## What Changes When You Apply

| Surface | Effect |
|---|---|
| How far the Gantt scrolls | Bounded to the scheduled range plus your buffers |
| The schedule and its dates | Unchanged, limits are display only |
| Other machines | Unaffected, configuration is per machine |

## How to Check It Worked

1. Scroll the timeline to the far left and confirm it stops at the earliest scheduled start plus your buffer, not at empty years before it.
2. Scroll to the far right and confirm the end bound behaves the same.
3. Confirm the plan is unchanged: the same jobs sit on the same dates.
4. If a genuinely early job is clipped, raise the Start Limit Buffer Weeks or switch Start Limit to NoLimit and apply again.

## Common Mistakes

**Confusing limits with zoom.** Limits bound how far you can scroll; zoom changes how much fits on screen. Use zoom to fit a range, limits to remove empty scrolling.

**Clipping an early job.** A tight start bound can hide a job that starts before the buffer. Raise the buffer weeks or use NoLimit.

**Forgetting to apply.** The change takes effect only after Save and Apply Now Configuration.

**Expecting the schedule to change.** Limits are display only. If a job is in the wrong place, the fix is scheduling, not the view.
