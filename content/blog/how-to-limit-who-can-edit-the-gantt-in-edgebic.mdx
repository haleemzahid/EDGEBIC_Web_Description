**Limiting Gantt editing in EDGEBIC by User Solutions is done in the scheduler Configuration under Appointment Permissions: clear checkboxes like Allow Drag, Allow Create, and Allow Delete to turn a station toward view-only, then save and apply.** These are display and interaction settings on the machine where you set them, separate from account roles. Here is how to lock a Gantt down.

For the drag behavior itself, see [how to change the drag mode on the Gantt](/blog/how-to-change-the-drag-mode-on-the-gantt-in-edgebic), and for account-level control, [how to add a user](/blog/how-to-add-a-user-in-edgebic). Every task in this library is mapped on the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- You know whether you want a machine-level display lock or an account-level restriction. Appointment Permissions are the former; roles are the latter.
- You can open the scheduler **Configuration** tab. It sits inside the Schedule area's Schedule View.
- You accept these settings are per machine. Each station keeps its own display configuration.

## Step 1: Open the Scheduler Configuration

Open the **Schedule** tab and select the **Schedule View** sub-tab. Beside the scheduler view is the **Configuration** tab. Click it. The configuration is organized into General, Views, Appearance, Time and Schedule, and Manufacturing tabs.

## Step 2: Find the Appointment Permissions Card

On the **General** tab, find the **Appointment Permissions** card. It is a set of checkboxes, each governing one Gantt gesture. Nothing here changes the schedule math: it only decides which interactions the Gantt on this machine allows.

## Step 3: Clear the Interactions You Want to Block

Decide how locked-down the station should be, then clear the matching boxes.

| Checkbox | Default | Clear it to |
|---|---|---|
| **Allow Create** | Off | Keep new appointments from being drawn |
| **Allow Edit** | On | Stop bars from being opened and changed |
| **Allow Delete** | Off | Keep bars from being deleted |
| **Allow Copy** | Off | Keep bars from being copied |
| **Allow Drag** | On | Stop bars from being moved in time |
| **Allow Resize** | On | Stop bars from being lengthened or shortened |
| **Drag Between Resources** | On | Stop bars from moving to another work center row |
| **Allow Conflicts** | On | Refuse dropping a bar into an occupied slot |
| **Multi-Select** / **Cell Multi-Select** | Off / On | Control multi-selection behavior |

For a view-only shop-floor station, clear **Allow Drag**, **Allow Resize**, and **Drag Between Resources**, and clear **Allow Edit** too if operators do not log actuals from the Gantt.

## Step 4: Save and Apply

Click **Save and Apply Now Configuration** at the bottom. The lock takes effect immediately on this machine. If you want to undo everything, **Reset to Defaults** returns the factory permissions.

## A Note on Allow Conflicts

Turning **Allow Conflicts** off does not make EDGEBIC capacity-check drags. The model is override and warn: a manual drag is the planner's call, and the next scheduler run resolves feasibility. So do not rely on the conflict checkbox to prevent overbooking. Real capacity control comes from the schedule engine, not this toggle.

## Appointment Permissions Versus Roles

These checkboxes lock the Gantt on one machine. To control what a person may do across the whole application regardless of which machine they sign in on, use roles and permissions under Security, covered in [how to add a user](/blog/how-to-add-a-user-in-edgebic). The two work together: a role decides whether someone reaches the schedule at all, and Appointment Permissions decide what the Gantt on this station lets them touch.

## What Changes When You Save

Only what the Gantt on this machine allows. No schedule data changes, and the settings do not follow the user to another PC. Another planner on a different station keeps their own configuration until you export yours and they import it.

## How to Check It Worked

Go back to the Gantt and try the gesture you blocked. If you cleared Allow Drag, a bar should not move when you try to drag it. If you cleared Allow Delete, the delete action should be unavailable. Confirm the interactions you left on still work, so a station meant to log actuals can still open a bar.

## Common Mistakes

- **Expecting the lock to follow the user.** Appointment Permissions are per machine. A person on another PC is unaffected.
- **Relying on Allow Conflicts for capacity.** It refuses a drop into an occupied slot but does not capacity-check. Feasibility is on the planner and the next run.
- **Locking a station that needs to log actuals.** Leave Allow Edit on where operators open bars to record hours.
- **Confusing this with roles.** For account-wide control, use Security roles, not these display checkboxes.
