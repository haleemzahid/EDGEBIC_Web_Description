**To extend short operation bars on the Gantt in EDGEBIC, open the Schedule View, go to the Configuration tab, and set Extend Op. if below Hours under the Operations group, then click Save and Apply Now Configuration.** Operations shorter than that value are drawn wider so they stay clickable. It is a display setting only and does not change the schedule.

Short operations, a quick inspection or a setup-only step, can shrink to a sliver on a zoomed-out timeline and become impossible to click. EDGEBIC by User Solutions solves this with a display minimum: any bar below a chosen number of hours is drawn at least that wide. The true duration is untouched; only the drawing changes.

## Before You Start

- **You have short operations that are hard to click** on the current timeline.
- **You can reach the Configuration tab.** It sits in the Schedule View beside the Scheduler sub-tab.
- **You understand this is display only.** Widening a bar never changes its real hours or the plan.
- **You know your usual zoom level.** The more zoomed out you work, the higher a value you may want.

## Step 1: Open the Configuration Tab

Open the **Schedule** tab, then the **Schedule View** sub-tab, then select **Configuration**. Stay on the **General** tab.

## Step 2: Find the Operations Group

Locate the **Operations** group. It holds the bar drawing options.

| Setting | Default | What it changes |
|---|---|---|
| **Extend Op. if below Hours** | 1.0 | Bars shorter than this many hours are drawn wider so they stay clickable, display only |

## Step 3: Set the Value

Enter the minimum, in hours. A value of `1.0` means any operation under an hour is drawn at least an hour wide. Raise it if you work zoomed out and still lose short bars; lower it toward zero if you want widths to track true duration exactly.

## Step 4: Apply the Change

Click **Save and Apply Now Configuration** at the bottom. The timeline redraws with short bars widened to the new minimum.

## What Changes When You Apply

| Surface | Effect |
|---|---|
| Narrow bars on the Gantt | Drawn at least the minimum width, so they stay clickable |
| The operation's real hours | Unchanged, the engine still uses true duration |
| Reports and actual times | Unaffected, they always reflect real hours |

## How to Check It Worked

1. Find an operation you know is only a few minutes long.
2. Confirm its bar is now wide enough to click and select.
3. Open the operation and check that its real start, end, and duration are unchanged, only the drawing widened.
4. If short bars still disappear when you zoom out, raise the value and apply again.

## Common Mistakes

**Expecting the schedule to change.** The setting only widens the drawing. Real hours, dates, and capacity are untouched.

**Setting it too high.** A large minimum makes many short bars look the same width and can create visual overlap between quick back-to-back steps. Zoom in or lower the value if that bothers you.

**Forgetting to apply.** The change takes effect only after Save and Apply Now Configuration.

**Reading widths as durations.** When the minimum is on, a bar's width no longer maps exactly to its hours. Use the reports and actual times for precise numbers.
