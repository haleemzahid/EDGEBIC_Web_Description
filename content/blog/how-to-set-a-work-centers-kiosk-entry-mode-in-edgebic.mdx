**To set a work center's kiosk entry mode in EDGEBIC by User Solutions, open the Work Centers tab, select the machine, click Edit, and set Actual Entry Mode to Hours Primary, Pieces Primary, or Both.** This decides which input the kiosk shows as the main field for that machine. It is a shop-floor display preference, not a scheduling rule, so it makes the operator's form match how the work is counted without changing how the job plans.

Getting this right removes friction at the point of entry. An operator who counts shots should not be asked for hours first, and one who watches a clock should not have to guess a piece count. The entry mode aligns the form with reality.

## Before You Start

- **The kiosk is in use** for the machine's operators.
- **You know how the work is naturally measured:** by elapsed time, by piece count, or both.
- **You understand this is a display hint,** not a scheduling change.

## Step 1: Open the Work Center

Open the **Work Centers** tab, select the machine, and click **Edit**.

## Step 2: Set Actual Entry Mode

Find the **Actual Entry Mode** setting and choose one of:

- **Hours Primary:** the kiosk shows elapsed hours as the main input. This is the default.
- **Pieces Primary:** the kiosk shows piece count as the main input. Use this for machines counted by output, such as molders or stamping presses.
- **Both:** the kiosk shows both inputs, for operators who confirm time and count.

## Step 3: Update

Click **Update**. The kiosk entry form for that machine now leads with the input you chose.

## Step 4: Align It With the Capacity Type

If the machine schedules in pieces, set its entry mode to Pieces Primary so the plan and the shop-floor form agree. The two settings are independent and are not synced for you, so set both deliberately when you configure the machine.

## What Changes When You Save

The kiosk data-entry form for that machine changes to lead with the input you selected. Nothing about scheduling changes: capacity, routing hours, and shift assignment are untouched. The entry mode is purely about which field an operator sees first, so a plan built before and after the change is identical.

## How to Check It Worked

1. Open the kiosk for that machine and confirm the primary input field matches what you set.
2. If you chose Both, confirm both the hours and the pieces fields are present.
3. For a pieces-based machine, confirm the capacity type and the entry mode agree, since they are set separately.

## Common Mistakes

**Assuming capacity type sets the entry mode.** It does not. A machine set to schedule in pieces still defaults to Hours Primary on the kiosk until you change the entry mode too. Set both.

**Expecting a scheduling effect.** Actual Entry Mode is a display hint. If a plan looks wrong, the cause is in the capacity type, routing hours, or shifts, not the entry mode.

**Leaving hours-first on a piece-counted machine.** Operators who count output will fight an hours-first form. Match the mode to how the work is measured.
