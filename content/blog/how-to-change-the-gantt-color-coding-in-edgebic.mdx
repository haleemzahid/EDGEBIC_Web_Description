**To change the Gantt color coding in EDGEBIC, open the Schedule View, go to the Configuration tab, and edit the Detail Schedule Operation States list on the General tab: each state has a color swatch and an active checkbox, and Save and Apply Now Configuration repaints both the bars and the legend.** The colors are a display setting in EDGEBIC by User Solutions, not a scheduling rule, so recoloring a bar changes what you see and nothing about what the engine computed.

This post covers the one task. To learn what each color actually means before you change it, read [Gantt colors and labels in EDGEBIC](/blog/gantt-colors-and-labels-in-edgebic); the full task library sits at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- You can reach the **Schedule** area and its **Schedule View** sub-tab.
- You understand that display settings are per user and per machine, not shared across the plant.
- You know which operation state you want to recolor. The states are Default, Overridden, Applied, Resource Replaced, Rescheduled, Actual Start Applied, Downstream Changed, ERP Actuals, Planned Applied, and the Completed shade.

## The Steps

1. **Open the Schedule area** and select the **Schedule View** sub-tab.
2. **Click the Configuration tab** (the gear icon beside the scheduler view). It opens on the **General** tab.
3. **Find the Detail Schedule Operation States list.** Each row is one operation state with a color swatch and an **active** checkbox.
4. **Click the swatch** for the state you want to recolor and pick a new color.
5. **Untick the active box** on any state you never want drawn. That state stops coloring bars and disappears from the legend.
6. **Click Save and Apply Now Configuration** at the bottom of the tab. The Gantt and the legend both repaint immediately.

If you want to move this palette to another machine, use **Export** to write the configuration to a file, then **Import** it on the target machine. **Reset to Defaults** returns every swatch to the factory colors.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Gantt bars | Every bar in the changed state repaints to the new color at once. |
| The legend | The legend strip mirrors the same swatch, so bar and legend stay in sync. |
| A switched-off state | Bars in that state fall back to their neutral drawing and the state leaves the legend. |
| The plan | Nothing. Colors are presentation only; no schedule date, work center, or hour moves. |
| Other users | Nothing, unless they Import your exported configuration. |

The one visual treatment that is not a plain color is the **Completed** shade. It paints an opaque fill over whatever state color a finished bar carried, so a completed operation reads as complete no matter what state it was in. That shade still has its own color and active flag in the same list, so you tune it exactly like the others.

## How to Check It Worked

Drag any bar into the state you edited, or pick a job that already sits there, and confirm the bar and the matching legend entry both show the new color. If a state you switched off still colors bars, you likely edited the swatch but left the active box ticked, or you did not press **Save and Apply Now Configuration**. Reopen the Configuration tab and confirm both.

## Common Mistakes

**Editing the color but forgetting to apply.** The Configuration tab stages your change; it does not take hold until you click **Save and Apply Now Configuration**. If the Gantt looks unchanged, that is almost always why.

**Recoloring the actual-versus-planned overlay here.** The overlay markers (actual start, actual end, early and late variance, in-progress) have their own colors on the **Manufacturing** tab, not in the operation-states list. If it is the overlay you want to restyle, see [how to show actual versus planned on the Gantt in EDGEBIC](/blog/how-to-show-actual-versus-planned-on-the-gantt-in-edgebic).

**Assuming everyone sees your colors.** The display configuration is per user and per machine. A colleague on another station keeps their own palette until they Import yours.

**Switching off ERP Actuals to hide a bar you dislike.** ERP Actuals outranks every other state on purpose, because it marks dates fed from an external system. Turning off its color does not change the underlying data; if the data is wrong, fix it at the source, not on the Gantt.
