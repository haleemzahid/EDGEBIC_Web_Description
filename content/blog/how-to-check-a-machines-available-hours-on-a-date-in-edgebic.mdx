**To check a machine's available hours on a date in EDGEBIC by User Solutions, open its per-day capacity view and read the shift default for that date.** That figure, adjusted by any override in the Capacity column, is exactly the number of hours the scheduler will offer the machine that day, so it is the authoritative answer for a promise or a what-if.

Planners guess at machine availability all the time, and the guesses are usually wrong because they forget an instance count, a downtime window, or a holiday. The per-day capacity view removes the guessing. This page is how to read it and how to diagnose a zero. For the full formula behind the number, read [how EDGEBIC calculates work center capacity](/blog/how-edgebic-calculates-work-center-capacity).

## Before You Start

- **You know the machine and the exact date** you are checking.
- **You know which shift matters,** because capacity is per shift. A machine that runs day and night has a separate figure for each.

## Step 1: Open the Per-Day Capacity View

On the work center's row, click the **📊** per-day capacity button. The **Per-Day Capacity** dialog opens with a stacked bar per day and a grid of daily figures. Alternatively, in the **Resource Calendar**, read the machine's capacity row for the date.

## Step 2: Set the Range to Include the Date

Adjust the **From:** and **To:** dates so the date you care about is in the list. The grid shows every day in the range with its figures.

## Step 3: Read the Figures

For the target date, read across:

| Column | Meaning |
|---|---|
| **Shift default (h)** | What the capacity formula gives: shift hours minus downtime and partial holidays, times instances, times utilization |
| **Capacity (h)** | The effective hours after any override; equals the shift default unless a day override is set |
| **Loaded (h)** | Hours already committed by the current schedule |
| **Overridden** | Ticked when a manual override applies |

The free hours are the capacity minus the loaded hours. That difference is what the machine can still absorb on the date.

## How the Number Is Built

The shift default for a date comes from a fixed formula:

```
available hours = (shift hours - downtime - partial-holiday overlap)
                  x number of instances
                  x utilization %
```

A daily override, if present, replaces the whole calculation for that date and shift. That is why the Capacity column can differ from the Shift default column: an override is in play.

## Diagnosing a Zero-Hour Day

If a date shows zero, work the gate chain in order. Any one of these produces a zero:

1. The machine is marked unavailable, or its effective date is later than the date.
2. The date is a work-center holiday for this machine.
3. The date is a whole-day plant holiday, which zeroes every machine.
4. It is a weekend and the machine does not run weekends.
5. A daily override is set to zero for that date and shift.
6. The shift does not run on that weekday, so it contributes no hours.

Checking these in sequence finds the cause fast. For the deeper version of this diagnosis, see [capacity shows zero for a work center](/blog/capacity-shows-zero-for-a-work-center-edgebic).

## How to Check It Worked

1. Confirm the shift default matches your mental math: for a one-instance 8-hour shift at full clock with no downtime, expect 8.
2. Confirm the Capacity column equals the shift default unless you meant to set an override.
3. Subtract loaded from capacity to get the genuinely free hours, and use that for the promise.

## Common Mistakes

**Reading the wrong shift.** Capacity is per shift. A day-and-night machine has two figures; check the one the job would run on.

**Confusing capacity with free hours.** The shift default is total capacity, not what is left. Subtract the loaded hours to see what the machine can still take.

**Forgetting the instance count.** A three-instance machine offers three times a single machine's hours. If the number looks too high or too low, check the instance count.

**Missing an override.** If the Capacity column differs from the Shift default, an override is set. Read the Overridden tick and the reason before trusting either number.
