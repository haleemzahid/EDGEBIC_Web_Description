**To add an ECN number to a product in EDGEBIC by User Solutions, open the Products tab, select the product, click Edit, and enter the number in the ECN Number field.** The same editor carries a Notes field for change detail and Manufacturer Part Number and Manufacturer Name fields for sourcing. These are reference fields for traceability: they record the change context against the product without affecting how it schedules.

An ECN number on the product record is the pointer that lets the shop trace a part back to the released change. It is deliberately lightweight, a label and a note, not a change-control system in its own right.

## Before You Start

- **The product exists.**
- **You have the ECN reference** and a short description of what changed.
- **You understand these fields are text,** not versioned change control.

## Step 1: Open the Product for Editing

Open the **Products** tab, select the product, and click **Edit**.

## Step 2: Enter the ECN Number

Type the engineering change notice reference into the **ECN Number** field. This is the traceability pointer back to the released change.

## Step 3: Add a Short Note

Use the **Notes** field for a brief description of what changed, for example `Revised wall thickness per ECN`. Keep it to a current-state summary, because this field is plain text with no version history and a new save overwrites the old text.

## Step 4: Update the Manufacturer Detail If It Changed

If the revision came with new sourcing, update **Manufacturer Part Number** and **Manufacturer Name**. Then click **Update** to save all the fields.

## What Changes When You Save

The ECN number, notes, and manufacturer fields are stored on the product and shown in its detail pane. Nothing about scheduling changes: routing, cost, and shift assignment are untouched. These fields are reference text, so the product plans exactly as before but now carries the change context anyone can read.

## How to Check It Worked

1. Reopen the product detail and confirm the ECN Number field shows the reference.
2. Confirm the Notes field shows your short description and the manufacturer fields, if you changed them, are correct.
3. If the change actually alters how the part is made, confirm you also updated the routing or cost, since the ECN field alone does not.

## Common Mistakes

**Expecting version history in Notes.** The field is plain text and a new save overwrites it. Keep the authoritative change record in document control and reference it from the ECN field.

**Assuming the ECN drives behavior.** It is a traceability label. A change that alters how the part is built must be reflected in the routing or cost fields, not just the ECN number.

**Confusing the product ECN with a routing note.** The ECN and Notes fields sit on the product. A note about a specific operation belongs on the routing step instead.
