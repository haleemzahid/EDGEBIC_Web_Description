**To schedule only the jobs on one sales order in EDGEBIC by User Solutions, set the sales order filter on the Orders toolbar to that sales order before you run Schedule.** The filter scopes both the grid and the scheduling run, so only the matching manufacturing orders are sent to the engine. The rest of the plan is left exactly as it was.

This is the precise tool for a single-customer-order change: pull-in dates, a quantity revision, a new order that needs slotting in. You handle it without a plant-wide rerun, and nothing on the other orders moves.

## Before You Start

- **The jobs are linked to a sales order.** The filter works on the sales order association, so each manufacturing order must reference its sales order first.
- **You know the sales order reference number.**
- **You will clear the filter afterward.** A filter left active silently scopes your next run.

## Step 1: Open the Orders Grid

Open the **Drive Schedule** tab and go to the **Orders** grid. The toolbar at the top carries the sales order filter control.

## Step 2: Set the Sales Order Filter

Use the **Sales Order** filter dropdown and select the sales order you want to schedule. The grid narrows to just its manufacturing orders.

This is the moment the scope is set. From here, both what you see and what the scheduler will run are limited to this sales order.

## Step 3: Select the Jobs

Tick the jobs you want to schedule. Because the grid is already narrowed, **Select All** picks only the filtered jobs, which is exactly what you want.

## Step 4: Choose the Mode and Run

Set the **Scheduling Mode**. Use Incremental New for a first schedule of new jobs on the order, or Reschedule to replan jobs that already have a plan. Click **Schedule / Re-Schedule** and confirm the summary dialog.

Only the manufacturing orders on the filtered sales order are sent to the engine. Every other job keeps its existing plan.

## Step 5: Clear the Filter

Use the clear control next to the filter dropdown to return the view to **All**. This is not optional housekeeping: the filter scopes the next run too, so a plant-wide schedule started with the filter still set will quietly cover only this one order.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Jobs on the filtered sales order | Scheduled or rescheduled per the mode |
| Jobs on other sales orders | **Unchanged.** Existing plan preserved |
| Orders grid | Shows only the filtered order until you clear |
| The next run, if filter still set | Scoped to this order again |

## How to Check It Worked

1. On the Job View, confirm the jobs from that sales order have updated bars.
2. Spot-check a job on a different sales order and confirm its bars did not move.
3. Confirm the filter dropdown now reads **All** before you do anything plant-wide.

## Common Mistakes

**Leaving the filter set.** The most common failure. A later run that should cover the whole shop only touches this order, and it looks like the scheduler skipped everything. Clear the filter back to All when you finish.

**Confusing the filter with the selection.** The filter decides which jobs are in scope; the checkboxes decide which of those are selected. Both matter. If you filter but forget to select, the schedule-all offer still respects the filter, which is usually what you want.

**Scheduling an order whose jobs are not linked to it.** If a job is not associated with the sales order, the filter will not include it. Link the sales order to the job first.
