**A setup source is a short code that records which tier of the setup-time chain produced a step's setup time.** When the engine works out how long a changeover takes, it does not guess; it walks a defined priority chain and picks the first rule that applies. The setup source names the rule that won, turning an otherwise unexplained number into a traceable answer. EDGEBIC by User Solutions stamps a setup source on every scheduled step so a planner can always see why a changeover is as long, or as short, as it is.

## How it works

Setup time is resolved through a chain, checked from most specific to most general. The engine first looks for a product-level matrix entry for the exact from-product to to-product changeover. If none exists, it tries the family-level matrix, which groups similar products. Failing that, it falls back to the step's flat setup time, and finally to the work center's default. The first level that matches sets the time, and the setup source records which level that was.

Some sources sit outside the chain. Cold start applies when a step is the first job on a machine with no prior product to change from. Same product applies when the previous job was identical, so the changeover is zero. A completed step keeps its setup as historical fact rather than recomputing it. A dependent parallel step mirrors its parent's setup. Each of these has its own source code so the reason is never ambiguous.

The value of the setup source is traceability. A setup time on its own is just a number. Paired with its source, it becomes an explanation you can act on: edit a matrix cell, add a missing entry, or adjust a default, depending on which rule the source says fired.

## A concrete example

Imagine a spray booth with a laminated changeover card and a running log of what was last sprayed. When the next job comes up, the operator checks the card: is there a specific line for this exact color change? If so, use that time. No specific line? Fall back to the color-family rule. No family rule either? Use the booth's standard changeover. And if the booth is just starting the day with nothing sprayed before, there is no cleaning to do at all.

The setup source is the note the operator writes down: "45 minutes, from the family rule, dark to light." Later, if someone questions the 45 minutes, that note points straight to the family rule rather than leaving them to guess whether it came from a specific cell or a default.

In the plant, a step's setup source might read matrix family with 45 minutes, or cold start with the booth's opening changeover, or same product with zero. Each reads back the exact reason for the time.
