**To restore a default grid layout in EDGEBIC, open Settings and then the Data Management tab and use Reset UI Layouts to Factory Defaults, or use the Reset to Defaults button inside a single view's own configuration dialog.** In EDGEBIC by User Solutions this snaps saved grids and panels back to how they shipped, clearing widths, order, visibility, sorting, grouping, and filters, and it is safe: layouts are presentation only, so restoring them never touches your schedule or your data.

This post covers restoring a layout. To save and keep the arrangement you build, see [how to save a grid layout in EDGEBIC](/blog/how-to-save-a-grid-layout-in-edgebic); the full task library is at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## What a layout reset touches, and what it does not

Layout persistence is broad on purpose. It covers the configurable grids and trees across the main tabs, the report panes, the dialogs, and the pickers, including the Job View job tree, and it stores your widths, order, visibility, pinning, sorting, grouping, and filters per grid and per user. A reset clears all of that for the scope you choose and shows the factory layout instead. What it never touches is a single row of data. It also does not disable the save behavior: the moment you rearrange the reset grid and navigate away, your new arrangement saves again automatically. So a reset is not a one-way door; it is simply a clean starting point you can build on top of.

## Before You Start

- You are signed in under your own account. Layouts are saved and reset per user.
- You know whether you want to reset one view or all of them. There is a narrow tool and a wholesale tool.
- You understand a layout is display only, so a reset never risks your data.

## The Steps

**Reset one view:**

1. **Open the view** whose grid or panel looks wrong.
2. **Open its configuration dialog.** For the scheduler, this is the **Configuration** tab in Schedule View.
3. **Click Reset to Defaults.** This returns that view's layout to factory settings.

**Reset all layouts at once:**

1. **Open Data Management.** From the main navigation open **Settings**, then the **Data Management** sub-tab.
2. **Choose the layout reset.** Click **Reset UI Layouts to Factory Defaults**.
3. **Confirm.** Every saved grid and panel layout snaps back to how it shipped, with all columns visible and no saved filter.

> The toolbar's Reset to Default button reaches the same area, but it sits alongside data-clearing options. Read its prompts carefully and choose only the UI configuration scope so you reset layouts without touching data.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Column widths, order, visibility | Return to the factory layout. |
| Pinning, sorting, grouping, filters | Cleared, so hidden rows reappear. |
| A single view (view-level reset) | Only that view resets; other layouts are kept. |
| All views (Data Management reset) | Every saved layout snaps to defaults. |
| Your data and the schedule | Nothing. Layout is presentation only. |

## How to Check It Worked

Open the grid you reset. Every column should be visible, in the factory order, with no grouping and no filter hiding rows. If rows you expected were previously hidden by a filter, they should reappear. Rearrange the grid again and navigate away; the new arrangement saves automatically, confirming the reset returned the grid to a clean, working state rather than disabling the save behavior.

## Common Mistakes

**Confusing the layout reset with data clearing.** The toolbar's Reset to Default button also reaches data-clearing options. Read the dialog and pick only UI configurations, or back up first, so you reset layouts without wiping tables.

**Sharing one account.** Layouts are per user. Two planners under one account overwrite each other's arrangement constantly. The lasting fix is separate accounts, not repeated resets.

**Resetting everything for one bad grid.** If only one view is wrong, use that view's own Reset to Defaults. The wholesale reset clears every screen's layout, which is more than you need.

**Assuming an update broke your columns.** A newly shipped column is merged into your saved layout, not dropped over it. Rearrange once and it re-saves cleanly, no reset required.
