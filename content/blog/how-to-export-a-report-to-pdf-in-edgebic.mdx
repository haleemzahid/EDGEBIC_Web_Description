**Exporting a report to PDF in EDGEBIC by User Solutions renders the report grid exactly as it appears on screen, so grouping, sorting, filters, and column widths all carry into the file.** That makes the setup step, not the export step, the one that decides whether the document is readable. Here is the whole task.

Every task in this library is mapped on the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub). For the report catalog itself, start with [how to run the late jobs report](/blog/how-to-run-the-late-jobs-report-in-edgebic).

## Before You Start

- The report is open and shows the rows you want. Exporting is a capture, not a query: it cannot include rows the report did not return.
- You know who is reading it. A customer document and an internal working file want different columns.
- You have a naming convention. Reports are point in time, and a PDF with no date in its name loses most of its value within a week.

## Step 1: Set the Grid Up First

This is the step people skip, and it is the one that matters. Everything you do to the grid now appears in the file.

- **Hide columns nobody will read.** Use the column chooser. Fewer columns means wider columns and a page that fits.
- **Sort so the important rows are first.** Most reports arrive sorted meaningfully already. If you re-sort, re-sort for the reader.
- **Group if the document is organized that way.** Grouping by work center or customer turns a flat list into a structured document. Method in [how to group a report grid by a column](/blog/how-to-group-a-report-grid-by-a-column-in-edgebic).
- **Expand or collapse groups deliberately.** The export captures the current state, so a collapsed grid gives you a summary and an expanded one gives you the detail.
- **Apply any filter you need.** Filtering is covered in [how to filter a report with the filter editor](/blog/how-to-filter-a-report-with-the-filter-editor-in-edgebic).

## Step 2: Export

Click **Export** in the report window. In the save dialog, choose **PDF** from the file type list, pick a location, name the file, and save.

Name it with the report and the date. A file called `late-jobs-2026-08-07.pdf` is self-explanatory in six months. A file called `report.pdf` is not.

## Step 3: Open the File and Read It

Open the PDF before you send it. Two things go wrong often enough to be worth a thirty second check.

1. **Columns cut off at the page edge.** The export preserved on-screen widths and the grid was wider than the page. Go back, hide columns or narrow them, and export again.
2. **Groups in the wrong state.** A collapsed grouped grid produces a summary document. If you wanted detail, expand and re-export.

## PDF or Excel

| Choose PDF when | Choose Excel when |
|---|---|
| The document leaves the plant | Someone will keep analyzing it |
| It is evidence of a decision on a date | It will be merged with other data |
| The layout must not change | The report has many columns |
| It goes into a management pack | The reader wants their own pivot |

Excel export is covered separately in [how to export a report to Excel](/blog/how-to-export-a-report-to-excel-in-edgebic).

## How to Check It Worked

- **Every column you wanted is fully visible.** Read the rightmost column on the last page, not just the first.
- **The row count is right.** If the report showed 48 rows and the file has 12, a filter or a collapsed group is doing something you did not intend.
- **The date is unambiguous.** Either in the file name or on the page. A dated export is what makes "we knew on the seventh" provable later.
- **It opens on someone else's machine.** Send one to yourself before you send twenty to a customer.

## Common Mistakes

- **Exporting first and tidying after.** The file is a snapshot. There is no formatting pass after the fact, so a messy grid produces a messy PDF.
- **Using PDF for a wide report.** Thirty columns will not fit on a page at any readable size. Use Excel or hide columns.
- **Assuming the PDF will refresh.** It never will. Re-run the report and export again when the plan changes, which for most reports is daily.
- **Sending a filtered export without saying so.** If the file shows one customer's jobs, put that in the file name. A filtered report that looks plant-wide is how wrong conclusions get quoted back at you.
