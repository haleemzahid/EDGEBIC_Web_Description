**To reassign a job to a different operator in EDGEBIC by User Solutions, open the Schedule View, set View by to Operator so the lanes become people, and drag the operation's bar to another qualified person's lane.** The drop is accepted only if the target person is qualified for the step's skill, and it writes a pin to that person. Dropping on the Unassigned lane clears the pin and returns the step to automatic staffing. The drag checks qualification, not hours, so the next scheduling run books hours honestly and will slide the step if the person cannot cover it.

This post is the reassignment gesture. It sets the same pin as the picker, covered in [how to set an operator pin](/blog/how-to-set-an-operator-pin-in-edgebic), and both sit inside the model in [operator and skill scheduling explained](/blog/edgebic-operator-and-skill-scheduling-explained).

## Before You Start

| Prerequisite | Why |
|---|---|
| The step has a Required Skill | Operator lanes and the reassignment drag only apply to skill-gated steps |
| The target operator is qualified for that skill | The drop is rejected if they are not certified |
| You accept override-and-warn | The drag checks qualification, not capacity |

## Step 1: Switch the Schedule View to Operator Lanes

Open **Schedule** and then **Schedule View**. In the view's display configuration, set **View by** to **Operator**. The lanes become people: every operator with planned work in the window, plus an **Unassigned** lane that collects operations with no crew plan. Skill-required bars carry a person glyph so you can pick them out.

## Step 2: Drag the Bar to Another Operator's Lane

Drag the operation's bar from its current operator's lane to the target person's lane and apply the change. If the target is qualified for the step's skill, the drop is accepted and a pin to that person is written. If not, the bar snaps back and names the reason, for example that the person is not qualified for the skill.

## Step 3: Or Drop on Unassigned to Clear the Pin

To undo a pin rather than move it, drop the bar on the **Unassigned** lane. This clears the operator pin, and the next scheduling run staffs the step automatically from the whole qualified pool. It is the visual equivalent of setting the step's Operator picker back to Auto.

## Step 4: Reschedule to Book It Honestly

The drag expresses intent and writes the pin immediately, but it does not check hours. Run a reschedule so the engine books the step's hours against the new person for real. If that person is overloaded in the window, the step slides. If the slide is acceptable, you are done; if not, the load needs to move differently.

## What Changes When You Reassign

| Surface | Effect |
|---|---|
| The step's pin | Set to the target operator, or cleared if dropped on Unassigned |
| The bar | Moves to the target lane immediately, in the overridden state |
| The next reschedule | Books hours for the new person and slides the step if they cannot cover it |
| The crew tooltip | Names the reassigned person after the next run |

The reassignment writes the same pin whether you use the Gantt or the picker, and the pin is stored with the job's preserved routing so it survives reschedules. How the engine turns that pin into booked hours is described in [how EDGEBIC books operator hours](/blog/how-edgebic-books-operator-hours).

## How to Check It Worked

The bar sits in the target operator's lane, and after a reschedule the step's crew tooltip names that person. If the drop snapped back, the target was not qualified: certify them or pick a qualified colleague. If the step slid later after rescheduling, the new person could not cover the hours in the original window, which is the honest booking working.

## Common Mistakes

- **Expecting the drag to check capacity.** It checks qualification only. The reschedule books hours and may slide the step.
- **Trying to reassign a step with no required skill.** Only skill-gated steps appear in operator lanes. Set a Required Skill first.
- **Forgetting to reschedule.** The pin is written on drop, but hours are booked on the next run. Without it, the plan does not reconcile the change.
- **Dropping on the wrong lane.** Unassigned clears the pin entirely. If you meant to move to a person, target their lane specifically.
