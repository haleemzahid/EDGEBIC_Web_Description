**To restrict the Job View to a date window in EDGEBIC, set the Start and End date pickers on the Job View tab: the Gantt strip then spans only those dates, and clearing either picker falls that edge back to the job's own first or last date.** The default window is today minus 7 days through today plus 3 weeks, which keeps recent history and near-term plan on screen without scrolling. The window is a view control in EDGEBIC by User Solutions, so narrowing it changes what draws and nothing about the plan itself.

This post covers the one task. To read the bars once they are on screen, see [reading the EDGEBIC Gantt: planned versus actual](/blog/reading-the-edgebic-gantt-planned-vs-actual); the full task library is at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- At least one job has been scheduled, so the Job View has operations to draw.
- You are on the **Job View** tab and have picked a job in the **Select Job:** dropdown.
- You understand that the window filters the drawing only. The header hours roll-up always sums the whole job.

## The Steps

1. **Open the Job View tab** and select a job in the **Select Job:** dropdown.
2. **Set the Start: picker** to the earliest date you want on the strip.
3. **Set the End: picker** to the latest date you want.
4. **To open one edge**, clear that picker. Start clears to the job's own first date; End clears to the job's own last date.
5. **To reset**, clear both pickers and the strip spans the job's full first-to-last range.

The default window (today minus 7 through today plus 3 weeks) is already set when you open the tab, so most days you never touch the pickers at all.

## What Changes When You Save

There is no save step. The window applies as soon as you change a picker.

| Surface | Effect |
|---|---|
| The Gantt strip | Draws only operations that fall inside the Start-to-End window. |
| The summary header | Unchanged. Total, Actual, Remaining, and Percent Complete always roll up the whole job. |
| The per-operation grid | Shows the job's operations regardless of the strip window. |
| The plan | Nothing. The window is a view bound; no schedule dates move. |

## How to Check It Worked

Read the strip against the pickers: the leftmost visible date should match Start (or the job's first date if Start is cleared), and the rightmost should match End. If an operation you expected is missing, confirm it falls inside the window before assuming anything is wrong. Operations before Start or after End correctly do not draw.

## Common Mistakes

**Reading a narrow window as lost work.** The window trims the drawing, never the data. Every operation still counts in the header roll-up. Widen the pickers or clear one to bring bars back.

**Setting End before Start.** The view clamps to a single day rather than blanking. If the strip suddenly shows one column, check that End is later than Start.

**Confusing this window with the scheduler Gantt's range.** The whole-plant scheduler Gantt on the Schedule View is a different control with its own default (today plus 30 days) and its own Refresh. Changing the Job View pickers does not affect it.

**Blaming the window for a filtered job.** If a whole job is missing rather than a few operations, the cause is usually the job filter or an unscheduled operation, not the date window. Check the job's checkbox and its schedule status first.
