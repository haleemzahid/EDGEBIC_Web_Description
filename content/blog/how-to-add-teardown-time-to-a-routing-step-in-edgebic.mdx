**To add teardown time to a routing step in EDGEBIC by User Solutions, enter the teardown hours on the step, then optionally turn on Show Teardown Time so the cleanup shows after the operation on the Gantt.** Teardown time is a cost and display figure. It adds to the routing step's total-time cost rollup and can be drawn as a segment after the operation, but it is not used in capacity allocation, so it does not push the next operation's start date later. Reach for it when you want post-run cleanup to appear in cost estimates and, if you choose, on the schedule view, without changing the plan's dates.

This recipe covers one specific task. For the setup figure that does reserve capacity, read [how to add setup time to a routing step](/blog/how-to-add-setup-time-to-a-routing-step-in-edgebic). For how the timing pieces fit together, see [how EDGEBIC composes step timing](/blog/how-edgebic-composes-step-timing) and [EDGEBIC Bill of Routing explained](/blog/edgebic-bill-of-routing-explained).

## Before You Start

- The routing open, with the step that carries the cleanup identified.
- The teardown duration in hours, and a decision on whether cleanup must also block the machine. If it must, plan to use setup time or a short operation, because teardown alone does not reserve capacity.
- Access to Settings if you want the teardown segment drawn on the Gantt.

## Step by Step

1. Open the **BOR** tab and select the routing.
2. Select the step that carries the cleanup or teardown.
3. Enter the teardown hours for that step. This value feeds the step's total-time cost rollup.
4. Click **Update Standard BOR** to save.
5. To render the teardown on the schedule, open **Settings**, go to the **Manufacturing** tab, and under the setup and queue time segment options turn on **Show Teardown Time**. The Gantt then draws a teardown segment after the operation.
6. Run **Generate Schedule** if you want the cost or display change reflected in a fresh plan.

## What Changes When You Save

Saving the teardown hours updates the cost math right away: the step's total time now includes the cleanup, so the routing's estimated cost and any new quote simulation reflect it. The scheduled operation window does not grow, because teardown time is a cost element and reserves no capacity. With Show Teardown Time on, the Gantt draws a teardown segment after the operation, which is a visual overlay only. No dates shift from teardown time alone. If cleanup must actually block the machine or delay the next step, use setup time on the following job or model the cleanup as its own short operation, since those are the figures the scheduler acts on.

## How to Check It Worked

Open the routing's cost estimate or run a quote simulation and confirm the total reflects the added cleanup time. If you enabled Show Teardown Time, open the Job View Gantt and look for the teardown segment after the operation. Confirm the next operation's start date has not changed, which is correct: teardown time is not a scheduling delay, so if a date moved, another field is responsible.

## Common Mistakes

- **Expecting teardown to hold the machine.** It does not reserve capacity. If cleanup must block the machine, use setup time on the next run or a short operation.
- **Confusing teardown with setup.** Setup extends the scheduled window and is reserved before the run. Teardown is cost and display only after the run. They are not interchangeable.
- **Hunting for the segment without enabling it.** The teardown segment does not appear on the Gantt until Show Teardown Time is turned on in Settings, and it is off by default.
