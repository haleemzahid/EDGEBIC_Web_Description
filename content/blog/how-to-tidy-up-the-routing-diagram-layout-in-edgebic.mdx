**To tidy up the routing diagram layout in EDGEBIC by User Solutions, drag the nodes into the arrangement you want on the designer canvas and save with the update button.** Positions are stored with the routing, so the drawing opens the same way for everyone next time. Nothing about the routing itself changes: the running order lives in the connectors, not in where the boxes sit.

A routing diagram earns its keep when somebody can read the process off it without asking questions. That takes about two minutes of arranging on a typical routing, and it is worth doing once properly rather than fighting the same tangle every time you open the product.

## Before You Start

- **The routing exists and its steps are connected.** Layout is the last job, not the first. [How to build a routing as a flow chart in EDGEBIC](/blog/how-to-build-a-routing-as-a-flow-chart-in-edgebic) covers building one.
- **You know the real process order.** You are drawing what happens on the floor, so the sequence has to be settled first.
- **You have edit rights on the routing.** Saving the layout uses the same save as saving the routing.
- **You know which routing you are in.** The product's standard routing and a scheduled job's own copy are different drawings with different save buttons.

## Step 1: Open the Designer

Open the **BOR** tab, select the routing, and click **Designer** on the toolbar next to **Data Grid**. The diagram loads, briefly showing a loading message on a large routing.

Three areas matter:

| Area | What it gives you |
|---|---|
| **Toolbox** (left) | Work centers and products you can drag onto the canvas |
| Canvas (center) | The diagram itself. Select a node to edit it, drag it to move it |
| Toolbar (top) | Update (save), Clear, zoom in, zoom out, fit to window, the connector toggle, and add annotation |

## Step 2: Fit the Whole Diagram on Screen

Click **Fit to Window** first. It scales the diagram so every node is visible at once.

Do this before you move anything. On a routing that has been edited a few times, a node has usually drifted somewhere unhelpful, and fit to window is how you find it. It also gives you an instant count: if you expect nine steps and see eight nodes, you have found a problem before you started rearranging.

## Step 3: Lay the Steps Out in Reading Order

Drag each node into position. The layout that works for almost every routing is the simplest one:

- **Flow left to right.** First operation on the left, the end product node on the right.
- **One row per path.** A straight sequential routing is a single row. A branch gets its own row.
- **Sub-assemblies underneath.** Put a feeder line on a second row and let its connector rise into the step that consumes it.
- **Even spacing.** Equal gaps between nodes make a missing connector obvious, because the eye expects an arrow in every gap.

The end product node moves like any other node and its position is stored with the routing, so put it where the diagram ends rather than leaving it wherever it started.

## Step 4: Zoom In to Check the Connectors

Use **Zoom In** on any area where arrows cross or nodes sit close together.

Connectors carry the meaning of the routing, so this is the moment to confirm each one goes where you think. Every chain must arrive at the end product node, and any step whose link is missing or points at a deleted step is a real fault rather than a cosmetic one. [How to connect two steps in the routing designer in EDGEBIC](/blog/how-to-connect-two-steps-in-the-routing-designer-in-edgebic) covers drawing and correcting them.

## Step 5: Save

Click **Update** on the toolbar, tooltip save.

This writes both the routing and the node positions. Skip it and the arrangement is discarded the moment you switch to the data grid or close the designer.

## How to Check It Worked

1. **Close and reopen the designer.** The diagram should come back exactly as you arranged it. This is the only proof that the positions saved.
2. **Fit to window again.** Every node should be visible, none stacked on another.
3. **Read the diagram out loud.** Follow the arrows from the first step to the end product node. If you can narrate the process without hesitating, the layout is doing its job.
4. **Check the grid still agrees.** Switch to data grid mode: the steps and their next-in-sequence values are unchanged, because layout never touches them.

## Common Mistakes

**Arranging and then leaving without saving.** The most common cause of a diagram that keeps reverting.

**Using the clear button to tidy up.** Clear empties the canvas. It is not a layout tool, and reaching for it in a tidy-up session is an expensive misunderstanding.

**Laying out right to left.** Nothing stops you, and everyone who opens it afterward reads the process backward.

**Leaving the end product node in the middle.** It is the terminal node of every chain. Put it at the end of the drawing so the arrows resolve somewhere sensible.

**Confusing a tidy diagram with a correct routing.** A beautifully arranged drawing with a broken link still schedules in the wrong order. Zoom in and check the arrows.
