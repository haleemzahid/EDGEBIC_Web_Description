**To rename a work center in EDGEBIC by User Solutions, open the Work Centers tab, select the machine, click Edit, change the Name, and click Update, then update the routing steps that reference it.** The rename itself is one field. The part that catches people is the second half: routing steps store the work center name as text, and the scheduler matches on that text, so a rename without a routing update leaves steps with no machine.

This is the most common cause of a step that schedules with no resources, and it is entirely avoidable if you treat the rename as a two-part job from the start.

## Before You Start

- **You know which routings use the machine.** Note the products that route through it before you rename, so you know exactly what to fix.
- **You can edit routings and rerun the scheduler.**
- **You understand the rename is two steps:** the machine, then every routing that names it.

## Step 1: Rename the Work Center

Open the **Work Centers** tab, select the machine, and click **Edit**. Change the **Name** field, then click **Update**.

The machine is now renamed everywhere it is referenced by its stable identifier. That covers most of the system, but not the routing name text, which is the next step.

## Step 2: Update the Routing Steps

Open the **Bill of Routing** for each product that routes through the machine, in the Grid View. Each step that uses the machine carries the work center name as text. Change that text to the new name.

This is the load-bearing step. The scheduler matches a routing step to a machine by this name, so a stale name means the step finds no machine and schedules with no resources.

## Step 3: Save Each Routing

Click **Save Steps** on each routing you edited. Work through the full list of products that route through the machine before moving on.

## Step 4: Reschedule and Confirm

Run **Schedule / Re-Schedule**, then confirm the renamed machine still receives its work. A step that came back with no resources is the signal that a routing name was missed.

## What Changes When You Save

| Surface | Effect |
|---|---|
| The work center | Renamed everywhere it is referenced by identifier |
| Routing step name text | **Must be updated by hand** to match |
| Scheduler name match | Fails on any step still carrying the old name |
| Gantt display color | Unchanged; color is a separate setting |

## How to Check It Worked

1. Confirm the Work Centers grid shows the new name.
2. Open a routing that used the machine and confirm the step now shows the new name.
3. Run the scheduler and confirm the machine receives work. Look specifically for any operation that scheduled with no resources, which points at a routing you missed.
4. Check a dispatch list or the utilization report for the machine to confirm its jobs are intact under the new name.

## Common Mistakes

**Renaming the machine but not the routings.** The single most common consequence. Steps that still name the old machine schedule with no resources. Update every routing that references it.

**Assuming one save covers everything.** The rename is two parts: the machine, then each routing. There is no single button that rewrites the routing name text for you.

**Expecting the color to follow the name.** The Gantt color is a separate setting. Rename changes the name only; edit the color swatch if you want that different too.
