**To copy your scheduler display settings in EDGEBIC, open the Schedule View, go to the Configuration tab, and use Export to save the configuration to a file and Import to load it on another machine, then click Save and Apply Now Configuration.** Reset to Defaults returns everything to factory settings. These settings are display only and never change the schedule.

The Configuration tab in EDGEBIC by User Solutions holds every presentation and interaction setting for the scheduler and Gantt: colors, operation labels, the actual-versus-planned overlay, setup and queue segments, timeline limits, and how drag edits are batched. This configuration is stored per machine, not in the shared database, so a reinstall or a new workstation starts at factory defaults. Export and Import are how you carry a tuned configuration between machines in one step.

## Before You Start

- **You have tuned a configuration worth keeping**, or you want to reset one that has drifted.
- **You can reach the Configuration tab.** It sits in the Schedule View beside the Scheduler sub-tab.
- **You know these settings are display only.** Copying them never moves a job or changes capacity.
- **You have file access on both machines** if you are transferring between computers.

## Step 1: Open the Configuration Tab

Open the **Schedule** tab, then the **Schedule View** sub-tab. Beside the **Scheduler** sub-tab, select **Configuration**. This is the display and interaction settings area, organized into General, Views, Appearance, Time and Schedule, and Manufacturing tabs.

## Step 2: Export the Configuration

Click **Export** at the bottom of the Configuration tab. Save the file somewhere you can reach it, for example a shared folder or a USB drive. This file captures the whole display configuration as currently set.

## Step 3: Import on the Other Machine

On the target machine, open the same **Configuration** tab and click **Import**. Choose the file you exported. The display settings load in.

## Step 4: Apply the Change

Click **Save and Apply Now Configuration** at the bottom. The imported settings take effect immediately on that machine.

## Optional: Reset to Defaults

To discard a configuration and start clean, click **Reset to Defaults**, then **Save and Apply Now Configuration**. This returns every display setting to factory values, which is the fastest recovery when experimenting has gone wrong.

## What Changes When You Apply

| Surface | Effect |
|---|---|
| The current machine's display | Colors, labels, overlays, and drag behavior update to match the file |
| The schedule and its dates | Unchanged, these settings are display only |
| Other machines | Unaffected, each machine keeps its own configuration until you import to it |

## How to Check It Worked

1. After importing, confirm a distinctive setting you rely on, for example the operation label pattern or the actual-versus-planned overlay, now matches the source machine.
2. Open a job on the Gantt and verify the bar colors and segments look the same as on the tuned machine.
3. Confirm the schedule itself is identical: the same jobs on the same dates, since only the display changed.
4. If anything looks off, re-Import the file, or Reset to Defaults and start again.

## Common Mistakes

**Forgetting to apply.** Import loads the settings, but they only take effect after Save and Apply Now Configuration.

**Expecting the schedule to change.** These are display settings. If the plan itself looks wrong, the fix is in master data or scheduling policy, not here.

**Not keeping an export.** Once a configuration is tuned, Export it. Recovery then costs one Import instead of re-clicking dozens of options.

**Assuming it is shared.** Display configuration is per machine. A colleague on a different computer keeps their own until you import your file to it.
