**To change what a Gantt bar label shows in EDGEBIC, open the Schedule View Configuration tab, find the Resource Display card on the General tab, and edit the Op. Description Pattern: pick fields from the Data Source list, press Add to build the pattern, set the Delimiter, then Save and Apply Now Configuration.** The label is a per-work-center display template in EDGEBIC by User Solutions, so you decide exactly which schedule fields each lane prints on its bars.

This post covers the one task. For the wider set of display switches around it, read [EDGEBIC configuration options explained](/blog/edgebic-configuration-options-explained); the full task library lives at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- You can reach the **Schedule** area and its **Schedule View** sub-tab.
- You know whether you want to change one work center's labels or every lane's at once.
- You know which fields you want on the bar. Common choices are job number, end product, remaining hours, and quantity.

## The Steps

1. **Open the Schedule area** and select the **Schedule View** sub-tab.
2. **Click the Configuration tab** and stay on the **General** tab.
3. **Select the work center** whose bars you want to relabel (the pattern is stored per work center).
4. **Open the Resource Display card** and find the **Op. Description Pattern** field.
5. **Pick a field from the Data Source list** and press **Add** to drop it into the pattern. Repeat for each field you want.
6. **Set the Delimiter** (the default is a vertical bar) so the fields read clearly when joined.
7. **Press All WCs** if you want this exact pattern applied to every work center instead of only the selected one.
8. **Click Save and Apply Now Configuration.** Every affected bar rebuilds its caption from the new pattern.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Bar captions | Every operation bar on the affected work center redraws its text from the new pattern. |
| Other work centers | Unchanged, unless you pressed All WCs to copy the pattern to every lane. |
| The plan | Nothing. The label is text drawn from existing schedule data; no dates or hours move. |
| Hour tokens | If your pattern includes actual or remaining hours, EDGEBIC runs a one-time backfill so those numbers are populated on the bars. |

A short, pointed pattern beats a long one. A caption of job number, end product, and remaining hours answers almost every "what is this bar" question a supervisor has without opening anything.

## How to Check It Worked

Read any bar on the work center you edited. The caption should show exactly the fields you added, in order, separated by your delimiter. If a field reads as blank or zero where you expect a value, check that the field actually carries data for that operation: a material step with no work center shows no run hours, for example, and hour tokens on a freshly loaded view can take a moment to fill while the backfill runs.

## Common Mistakes

**Editing one lane and expecting all of them to change.** The pattern is per work center. Build it, then press **All WCs** if you meant it everywhere.

**Overloading the caption.** Fields keep adding, and a bar can only fit so much text. If the label runs off the bar, cut it back to the two or three fields that matter, or raise the minimum bar width so short bars stay readable (the "extend below hours" setting on the same tab controls that).

**Confusing the bar label with the BOR Designer node text.** The routing designer's node captions use their own separate pattern and do not fall back to the Gantt pattern. If it is the designer nodes you want to change, edit them in the Designer's node display fields, not here.

**Adding hour tokens and reading the first paint as broken.** Actual and remaining hours are backfilled on demand only when those tokens are present. The very first render after you add them may lag while the numbers fill; refresh once and they settle.
