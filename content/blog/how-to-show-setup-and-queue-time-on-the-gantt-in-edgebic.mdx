**To show setup and queue time on the EDGEBIC Gantt, open the Schedule View Configuration tab, go to the Manufacturing tab, and use the Setup and Queue Time card: turn on Show Setup Time and Show Queue Time, optionally Show Teardown Time and Show Move Time, then click Save and Apply Now Configuration.** In EDGEBIC by User Solutions this draws setup, queue, and transport time as their own segments on each bar so the board reads honestly, and it is display only: the times come from your routing and the card changes only how they are shown.

This post covers one display card. For the wider map of what is presentation versus what is policy, see [the settings that change how your schedule looks in EDGEBIC](/blog/the-settings-that-change-how-your-schedule-looks-edgebic); the full task library is at the [EDGEBIC how-to hub](/blog/edgebic-how-to-hub).

## Before You Start

- You can reach the **Schedule** area and its **Schedule View** sub-tab.
- Your routings actually carry setup or queue time, or there is nothing new to draw.
- You understand these are display settings, saved per station, that never change the plan.

## The Steps

1. **Open the Configuration tab.** In the **Schedule** area, open **Schedule View**, then the **Configuration** tab beside the scheduler.
2. **Go to the Manufacturing tab.** Inside Configuration, select the **Manufacturing** tab.
3. **Find the Setup and Queue Time card.** Locate the card labeled **Setup and Queue Time**.
4. **Turn on the segments you want.** Tick **Show Setup Time** to draw setup as its own segment at the start of the bar, and **Show Queue Time** to draw the queue buffer as a zone before the operation. Both are on by default.
5. **Add transport segments (optional).** Tick **Show Teardown Time** and **Show Move Time** if you want those zones drawn. Both are off by default.
6. **Simplify if needed.** Tick **Combine Setup with Runtime** to merge setup into the run segment for a cleaner bar.
7. **Apply.** Click **Save and Apply Now Configuration** at the bottom. **Reset to Defaults** returns the whole tab to factory settings.

## What Changes When You Save

| Surface | Effect |
|---|---|
| Show Setup Time | Setup renders as its own segment at the start of each bar. |
| Show Queue Time | The queue buffer renders as a zone before the operation. |
| Show Teardown / Show Move Time | Draw those zones after or between operations when on. |
| Combine Setup with Runtime | Folds setup into the run segment for a single cleaner block. |
| The plan and the data | Nothing. The times come from routing and work-center data; only the display changes. |

## How to Check It Worked

After applying, open a job whose routing has setup or queue time and look at its bar. With **Show Setup Time** on, the changeover should appear as a distinct segment at the start; with **Show Queue Time** on, the buffer should sit as a zone before the operation. Turn a segment off and apply again to confirm it disappears while the operation stays where it was. Because these are display settings, the bar's overall position never moves.

## Common Mistakes

**Expecting new time to appear.** These settings draw times that already exist in your routing. If a bar shows no setup segment, the routing may carry no setup time, not a display fault.

**Cluttering every bar with every segment.** Teardown and move segments are off by default for a reason. Turn on only what the reader of the board needs.

**Confusing the two setup controls.** Show Setup Time draws setup as its own segment; Combine Setup with Runtime hides it inside the run. Pick one intent, not both.

**Assuming everyone sees your bars.** Display configuration is per station. Export your configuration and have colleagues import it if you want a shared look.
