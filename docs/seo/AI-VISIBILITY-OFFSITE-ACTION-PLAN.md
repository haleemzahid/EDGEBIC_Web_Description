How this was researched: every domain the report cited was searched and, where the page could be fetched, read in full for any mention of "User Solutions", "Resource Manager", "RMDB" or "EDGEBIC". Pages that returned 403/404 to the fetcher are marked "unverified" and should be opened manually. Everything else below was verified on 2026-08-28.

## 1. Headline findings

1. The "Top 10 best ... software of 2026" pages on gitnux.org, wifitalents.com, zipdo.co and worldmetrics.org are one publisher network (identical template, identical "For software vendors: Apply to get listed" email CTA, near-identical vendor lists). Together they account for 27 citations in the report. User Solutions is absent from every one of them. This is the single largest fixable gap.
2. jitbase.com (10 citations) has published at least five 2026 listicles by the same author (Judicael Deguenon). User Solutions is absent from all of them. This is a competitor vendor blog, so inclusion is a courtesy ask, not a directory submission.
3. Directory coverage is uneven. Capterra (US/UK/AU/DE), GetApp UK, SoftwareAdvice UK/IE, SourceForge, Slashdot, SoftwareConnect and TopBusinessSoftware all list Resource Manager DB. G2 has a product page with 0 reviews and no pricing. Crozdesk has no listing. Every existing listing is stale: last Capterra review 28 May 2020, listings still say "Resource Manager DB", and none of the fetched listings mention EDGEBIC by name except the Capterra US pricing tier text ("EDGEBIC for a single named user").
4. There is no Wikipedia route. Neither "Advanced planning and scheduling" nor "Scheduling (production processes)" lists vendors, and the APS article carries a "needs more citations" banner. Adding a vendor would be reverted. The realistic play is to be cited as a reference for a factual claim, not listed as a vendor.
5. Existing third-party mentions all use old product names (Resource Manager for Excel, Workcenter Scheduler XL, RM-DB) and are 2016 to 2023 vintage: cioapplications.com (2016), processingmagazine.com and GlobeNewswire (April 2020), PRNewswire (Oct 2023). LinkedIn company page has 44 followers and does not mention EDGEBIC.
6. One 2026 listicle already includes RMDB: horizonsolutions.ai (author Ben Van Delm) under "Job shop and custom manufacturing schedulers". It uses the RMDB name, not EDGEBIC. Worth a thank-you and a name update.
7. No Reddit, Practical Machinist, CNCZone or Eng-Tips mention of User Solutions/RMDB could be found via search. Practical Machinist threads returned 403 to the fetcher, so this is "unverified", but search snippets show no hit.
